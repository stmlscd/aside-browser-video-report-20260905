# Gmail 초안 작업 명세 · 작성자 적용 예시
이 명세는 초안 작성용입니다. 실제 메일 작성·발송은 실행하지 않았습니다.

지정한 Gmail 계정에서 미팅 확인 메일 초안을 작성해줘.
수신자: [이메일 주소]
미팅 날짜: [YYYY-MM-DD]
시간·시간대: [15:00, Asia/Seoul 등]
목적: 위 날짜와 시간의 미팅이 맞는지 짧고 정중하게 확인.

수신자 주소나 기준 날짜가 없으면 추측하지 말고 먼저 확인해줘. ‘내일’ 같은 상대 날짜는 실행 기준일과 함께 절대 날짜로 바꿔 확인해줘.
제목과 본문을 입력하되 전송 버튼은 누르지 마. 첨부파일과 참조·숨은참조는 요청하지 않은 항목을 추가하지 마.
Gmail에 초안을 저장하면 데이터가 해당 서비스에 저장된다는 점을 전제로, 승인된 내용만 작성해줘.
완료 후 계정·수신자·제목·본문·아직 발송하지 않았음을 보여줘.
