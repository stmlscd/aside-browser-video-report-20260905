# Use routines

Routines let Aside run recurring work without starting each task by hand.

## Routine types

| Type              | Behavior                                 |
| ----------------- | ---------------------------------------- |
| Cron routine      | Starts a new task on a schedule.         |
| Heartbeat routine | Wakes an existing chat and continues it. |

Use a cron routine for standalone repeat work, such as a weekly summary. Use a heartbeat routine when the same chat should continue later with new context.

Aside skips overlapping routine runs and pauses routines when their target chat is unavailable.

## Manage routines

Open `Settings > Routines`.

From the routine list, you can:

* Create a routine
* Edit instructions or schedule
* Pause or resume a routine
* Delete a routine
* Run a routine now
* Review active routines and draft suggestions

Free plan users can keep up to 3 active routines. Pro users can create unlimited active routines.

## Use routine suggestions

Routine suggestions are draft routines. Aside can scan for recurring work and propose routines.

1. Open the routine list.
2. Choose `Find routine suggestions` or `Find more suggestions`.
3. Review the draft suggestion.
4. Edit the instructions, schedule, or target chat.
5. Choose `Activate`.

Use `Dismiss` for a suggestion you do not want.
