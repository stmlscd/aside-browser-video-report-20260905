# Get started with Aside

Aside runs tasks in the browser. It can use websites, accounts, browsing history, files, and saved credentials according to your settings.

## Before you start

You need an Aside account and the Aside browser components installed.

Download Aside from [aside.com/download](https://aside.com/download). Aside supports macOS 15.0 or later. There is no separate minimum browser version because Aside is the browser.

## Set up Aside

1. Open Aside.
2. Sign in or create an account.
3. Import browser data.
4. Set up Password Manager.
5. Start a task.

## Import your browser data

Browser import brings over the context you already use while browsing.

Aside can import:

* Browsing history
* Cookies
* Bookmarks

1. Open import during onboarding.
2. Choose a profile.
   If Aside finds multiple profiles, choose the profile you want to import.
3. Allow system access.
4. Wait for import to finish.
5. Continue to password setup.

Safari uses file import. In Safari, choose `File > Export`, then upload the ZIP file Safari creates. Aside rejects non-ZIP files for this flow.

## Start your first task

1. Start a task from the task page or side panel.
2. Describe the outcome.
   Name the website, account, file, or result you want.
3. Choose permissions if needed.
   Choose a permission mode and working folder if the task needs files.
4. Send the task.

Use the task page for work that spans sites, accounts, or files. Use the side panel when the current page should become task context. See [Run tasks](/help/tasks) and [Use the side panel](/help/side-panel).
