# Manage privacy

Aside can use accounts, browsing history, site data, saved credentials, and task files. Set privacy controls around the data you want Aside to keep.

## Privacy settings

Open `Settings > Security & Privacy`.

Current privacy controls include:

* Delete browsing history
* View browsing history
* Third-party cookies
* Analytics sharing
* Ad privacy
* Site settings
* Advanced DNS, SSL, and Safe Browsing settings

Analytics sharing defaults to on. Aside reads the current third-party cookie setting and lets you choose `Allow` or `Block all` when the extension can control the setting.

`Ads privacy`, `Site settings`, and `Advanced` open the browser settings pages for ad topics, site permissions, DNS, SSL certificates, and Safe Browsing.

## Delete browsing history

1. Open `Settings > Security & Privacy`.
2. Choose `Delete browsing history`.
3. Choose the data types and time range.
4. Confirm deletion.

Time ranges are:

* `All time`
* `Last 15 min`
* `Last 30 min`
* `Last 24 hours`
* `Last 7 days`
* `Last 4 weeks`

Data types are:

* Browsing history
* Cookies and other site data
* Cached images and files
* Download history
* Autofill form data
* Site storage

Use this action for data stored in Aside's browser profile.

## Clear password vault data

Password vault reset lives in password settings. Export passwords first if you need a backup, then use `Settings > Passwords > Clear vault data`. See [Configure password autofill](/help/passwords#vaults-and-sync).
