# Use the side panel

Use the side panel when the current page should become task context.

## Start from a page

1. Open the page.
2. Open the Aside side panel.
3. Keep the page attachment if you want Aside to read the page.
4. Write the task.
5. Send it.

The page attachment shows the page title and hostname. Remove the attachment if you want Aside to start without that page.

## Use cases

Open the side panel from the page that should anchor the task. Keep the page attachment when Aside should read or act from that page.

## Drafts

Aside stores the side panel draft by page context. If you leave a page and return later, the draft can remain tied to the tab where you started it.
