# Manage memory

Memory helps Aside reuse context from your browsing history, chats, and tasks. Use memory settings to choose whether Aside creates memories and how long it keeps them.

## Turn memory on or off

Open `Settings > Memory > Configure`.

When memory is on, Aside can use browsing history as context and create memories from chats and task activity. Turn memory off when you do not want new chats or tasks to create memories.

## Choose retention

If memory is enabled, choose how long Aside keeps episodic memories:

* `Never forget`
* `30 days`
* `90 days`

Use shorter retention when you want Aside to forget day-to-day observations sooner.

## Review and edit memory

Open `Settings > Memory` to review what Aside remembers. Use `Overview` to inspect and edit saved memory, `History` to review memory changes, and `Configure` to change retention and other settings.
